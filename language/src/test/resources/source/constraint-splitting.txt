# How .ocl documents are split into constraints. Each case: "### name", the document, then "=> "
# lines: "files <unit>" per unit of ConstraintFiles.read, then "checker name=.. context=..
# severity=.. | <source>" per invariant of OclInvariantParser.parse, or "checker error
# <line>:<column> <message>". Texts have \n and \r escaped. A name ending in [crlf] uses CRLF line
# breaks, [noeol] omits the final line break, [fix] marks an accepted difference between
# ConstraintFiles and the splitter. Change expectations only for intended behaviour changes.
